# Moneymalist — Privacy Policy

Published at **https://moneymalist.github.io/privacy/**

Privacy policy for **Moneymalist — Expense Tracker** (`com.moneymalist`) on Google Play.

Moneymalist is offline-first: financial data stays on the device, there is no account system,
and the app contains no advertising or analytics SDKs.
